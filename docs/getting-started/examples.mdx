**This page contains a step-by-step example that demonstrates how to use Automock effectively.**

Please note that this example is agnostic to the testing framework (we'll use Jest) and any specific framework's adapter. The injection mechanism might differ based on the DI framework. For more details on the different adapters available and their specific functionalities, refer to the [Adapters Overview](../adapters/overview) page.
