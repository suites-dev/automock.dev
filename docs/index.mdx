# Automock Archived Documentation

This wiki is dedicated **exclusively to Automock archived documentation**.

Automock was a unit testing library that has been transformed into [Suites](https://suites.dev). This wiki preserves the original Automock documentation for historical reference and to assist users migrating from Automock.
